# Decisions

Store concise records of accepted choices that affect later work, such as validation design, target definition, feature availability, or model-selection policy.

Copy [the decision template](../templates/decision_template.md). Use this folder for lightweight shared decisions; keep formal architecture decisions in `docs/adr/` and link to them from the knowledge index when useful. A decision is not a finding: it records what the team chose and why, including tradeoffs and superseded alternatives.
