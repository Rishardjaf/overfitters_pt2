# Useful features

Store one candidate or validated predictive feature per file. Each entry must explain the feature precisely enough to reproduce it, including inputs, transformation, availability time, missing-value behavior, and leakage risk.

Copy [the feature template](../templates/feature_template.md). Do not label a feature `validated` without an out-of-sample comparison against an appropriate baseline and a link to the result. Related feature variants may share one file when they use the same rationale and validation.
