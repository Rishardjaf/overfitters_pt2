# Findings

Store one reusable investigation result per Markdown file. Good examples include a verified data-quality issue, a stable temporal pattern, an evaluation pitfall, or a reproducible failure mode.

Copy [the finding template](../templates/finding_template.md), rename it to a specific lowercase `snake_case` topic, and add it to [the index](../INDEX.md). Split a file when a future agent would reasonably need one conclusion without loading the others.

Keep raw plots and tables in their established output folders and link them here rather than duplicating them.
