# Conflicting findings

Use this folder when two evidence-backed claims cannot both be true within the same stated scope. Do not overwrite one claim, average the conclusions, or choose a winner based on confidence alone.

1. Copy [the conflict template](../templates/conflict_template.md).
2. Link both original findings and their evidence.
3. Check whether the disagreement comes from different data versions, cohorts, time windows, preprocessing, metrics, random seeds, or definitions.
4. Specify a reproducible test that could resolve the disagreement.
5. Add the conflict to [OPEN.md](OPEN.md) with an owner when one is known.
6. After resolution, record the result and evidence, update the source entries and main index, then move the row from open to resolved. Preserve the conflict file as history.
